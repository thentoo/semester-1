# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | Lists out the files and directories in the current working directory |
|     cd directory_name       | Go to the working directory "directory_name" |
|     cd ..                   | Change your working directory to your parent directory |
|     cd -                    | Change your working directory to your previous directory |
|     mkdir directory_name    | Make a new directory named "directory_name" |
|     touch filename          | Create a new file called "filename" |
|     git status              | Shows all the changes to be committed and general info |
|     git add -A              | Adds all files in the CWD to the commit |
|     git commit -m ""        | Commit the files with an empty message |
|     git push                | Push the commit to the repository |
|     git pull                | Download changes from a remote repo and integrate them into your current local branch |
